## 🚀 使用方法

### 方法一：使用 JMeter 测试

#### 1. 环境要求
- JMeter 5.4.3 或更高版本
- Java 8 或更高版本

#### 2. 运行测试

**图形界面模式**：
```bash
# 启动 JMeter
jmeter

# 打开测试脚本
文件 → 打开 → asset_system_test.jmx

# 运行测试
点击工具栏绿色启动按钮
```

**命令行模式**：
```bash
# 运行测试并保存结果
jmeter -n -t asset_system_test.jmx -l results.csv

# 生成 HTML 报告
jmeter -n -t asset_system_test.jmx -l results.csv -e -o report
```

#### 3. 查看结果
- 聚合报告：查看平均响应时间、吞吐量、错误率
- 查看结果树：查看每个请求的详细信息
- HTML 报告：打开 `report/index.html` 查看可视化报告

## 📊 测试场景

### 场景 1：资产查询接口测试
- **并发用户数**：100
- **测试接口**：`GET /asset/assetInfo/list`
- **预期响应时间**：≤2 秒
- **预期成功率**：≥99%

### 场景 3：资产入库申请测试

## 📈 性能指标说明

| 指标 | 说明 | 合格标准 |
|------|------|----------|
| 平均响应时间 | 所有请求的平均耗时 | ≤2 秒 |
| 90% 响应时间 | 90% 请求的响应时间 | ≤3 秒 |
| 吞吐量 (TPS) | 每秒处理请求数 | ≥50 req/s |
| 错误率 | 失败请求占比 | ≤1% |
| 并发用户数 | 同时在线用户数 | ≥200 |

---

## ⚠️ 注意事项

1. **测试前准备**
   - 确保后端服务已启动 (`http://localhost:8080/asset`)
   - 确保数据库连接正常
   - 关闭其他占用资源的程序

2. **测试环境**
   - 建议在测试环境进行，避免影响生产数据
   - 测试数据会在测试后清理

3. **结果分析**
   - 响应时间受网络、服务器负载影响
   - 多次测试取平均值更准确
   - 关注 90% 响应时间而非平均值
