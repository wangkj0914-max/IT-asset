图 3-1 系统 ER 图（实体关系图）

sys_user 用户表
PK user_id: BIGINT
username: VARCHAR
password: VARCHAR
real_name: VARCHAR
dept_id: BIGINT (FK)
role: TINYINT
status: TINYINT
sys_department 部门表
PK dept_id: BIGINT
dept_name: VARCHAR
dept_code: VARCHAR
manager: VARCHAR
phone: VARCHAR
status: TINYINT
asset_category 资产分类表
PK category_id: BIGINT
category_name: VARCHAR
parent_id: BIGINT
sort_order: INT
asset_info 资产信息表
PK asset_id: BIGINT
asset_code: VARCHAR
asset_name: VARCHAR
category_id: BIGINT (FK)
brand: VARCHAR
model: VARCHAR
purchase_price: DECIMAL
status: TINYINT
asset_use_record 领用记录表
PK record_id: BIGINT
asset_id: BIGINT (FK)
user_id: BIGINT (FK)
department: VARCHAR
contact_person: VARCHAR
approve_status: TINYINT
asset_repair_record 维修记录表
PK repair_id: BIGINT
asset_id: BIGINT (FK)
repair_reason: VARCHAR
repair_status: TINYINT
apply_user: VARCHAR
asset_scrap_record 报废记录表
PK scrap_id: BIGINT
asset_id: BIGINT (FK)
scrap_reason: VARCHAR
scrap_type: TINYINT
approve_status: TINYINT

关系说明：

  • sys_department → sys_user：1:N 关系，一个部门有多个用户
  • asset_category → asset_info：1:N 关系，一个分类包含多个资产
  • asset_info → asset_use_record：1:N 关系，一个资产有多条领用记录
  • asset_info → asset_repair_record：1:N 关系，一个资产有多条维修记录
  • asset_info → asset_scrap_record：1:N 关系，一个资产有一条报废记录
  • sys_user → asset_use_record：1:N 关系，一个用户有多条领用申请
